## 🚀 Getting Started

Follow the instructions below to set up and run the portfolio on your local machine.

### Prerequisites

Before getting started, ensure you have installed:

- [Node.js](https://nodejs.org/) (LTS version recommended).
- npm (included with Node.js).
- [Git](https://git-scm.com/).

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/smdevdesigns/Portfolio.git
```

**2. Navigate to the project directory**

```bash
cd Portfolio
```

**3. Install dependencies**

```bash
npm install
```

### Running the Application

Start the development server:

```bash
npm run dev
```

Once the server starts, open the local URL displayed in your terminal.

For Vite projects, the default address is usually:

```text
http://localhost:5173
```

### Building for Production

To create an optimised production build, run:

```bash
npm run build
```

### Previewing the Production Build

To preview the production version locally, run:

```bash
npm run preview
```

## 🌍 Deployment

The portfolio is deployed using [Vercel](https://vercel.com/).

**Live Application:**

[https://sophiamcg-portfolio.vercel.app/](https://sophiamcg-portfolio.vercel.app/)

### Deploying Your Own Version

To deploy your own instance:

1. Push your project to a GitHub repository.
2. Sign in to [Vercel](https://vercel.com/).
3. Select **Add New Project**.
4. Import your GitHub repository.
5. Configure the project build settings.
6. Set the build command to `npm run build`.
7. Set the output directory to `dist`.
8. Click **Deploy**.

Vercel will build and host your portfolio.
